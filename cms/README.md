# AGROINTELLECT Partner Hub CMS

Источник данных: Google Sheet `AGROINTELLECT Partner Hub — Контент и ссылки`.

Spreadsheet ID: `1qvrLJcVEeE9lsS5j3nGLzE_1niUQYCYTFtG8LgsR1og`

## Что управляется из таблицы

- Материалы и документы
- Ссылки и тип открытия
- Продукты и демо-доступы
- Интеграции
- Контакты
- Активность и порядок отображения

## Однократное подключение Apps Script

1. Открыть Google Sheet.
2. Расширения → Apps Script.
3. Удалить стандартный код и вставить содержимое `cms/Code.gs`.
4. Сохранить проект, например `Partner Hub CMS API`.
5. Нажать `Deploy / Развернуть` → `New deployment / Новое развертывание`.
6. Тип: `Web app / Веб-приложение`.
7. Выполнять от имени владельца таблицы.
8. Доступ — тот уровень, который соответствует модели доступа Partner Hub. Если сайт публичный и данные не секретны, endpoint может быть доступен всем. Если доступ к Hub должен быть закрытым, публичный endpoint использовать нельзя без отдельной авторизации.
9. Скопировать URL вида `https://script.google.com/macros/s/.../exec`.
10. В `cms/cms-loader.js` заменить пустое значение `window.PARTNER_HUB_CMS_URL` на URL развертывания и сделать один commit.

После этого изменения контента делаются только в Google Sheet. Код сайта переписывать не нужно.

## Логика обновления

Apps Script читает строки, где `Активно = TRUE`, сортирует по колонке `Порядок` и отдает JSON. Кэш по умолчанию 300 секунд. Значение меняется на листе `Настройки` в `cache_seconds`.

Для принудительного теста endpoint можно открыть с параметром `?refresh=1`.

## Fallback

Если Google Sheets/API временно недоступны, сайт продолжит работать на встроенном наборе данных из `legacy-v18.html`. Это защищает Partner Hub от падения при временных проблемах Google.

## Безопасность

Демо-логины и пароли находятся среди CMS-данных. Если endpoint Apps Script публичный, эти данные технически доступны любому, кто знает URL API. Для закрытого Partner Hub нужна авторизация или отдельная защищенная выдача credentials.
