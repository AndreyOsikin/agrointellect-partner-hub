# AGROИНТЕЛЛЕКТ Partner Workspace

Готовая статическая версия партнёрского кабинета.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html` и `.nojekyll`.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`.
6. Сохраните настройки. GitHub выдаст публичную ссылку.

Приложение не требует сборщика, npm или сервера: весь интерфейс, стили, логика и фотографии сотрудников встроены в `index.html`.

> Внешние Google Drive / Yandex Disk / Yonote документы могут запрещать отображение в iframe. Для таких случаев интерфейс показывает действие «Открыть отдельно».
